# Modular E-commerce Engine

A high-performance, containerized e-commerce solution built with Python (Flask). This engine manages product catalogs, shopping carts, and order processing with a modular architecture.

## 🚀 Key Features
- **Data Persistence:** Order management system using structured JSON logging.
- **Modern UI:** Responsive frontend built with HTML5 and CSS3.
- **Dockerized:** Fully containerized environment for consistent deployment.
- **Modular Code:** Decoupled logic for routes, utilities, and data handling.

## 🛠️ Tech Stack
- **Backend:** Python / Flask
- **Frontend:** HTML5, CSS3, JavaScript
- **DevOps:** Docker, Docker Compose
